Ayo Kita Main

Jalan-jalan di hutan, cari papan soal, baca soalnya, lalu tembak robot yang membawa jawaban yang benar!

Ganti model dengan file GLB

Pilih file bernama gun.glb, robot.glb, crate.glb, tree.glb, dan sign.glb (boleh sekaligus). Model yang tidak dipilih memakai bentuk sederhana.

Kelas berapa?

Kelas 1–6 SD, 7–9 SMP, 10–12 SMA. Makin tinggi kelas, makin sulit soalnya.

⬆
Cari papan soal, lalu tembak robot dengan jawaban benar. WASD jalan, tahan Shift untuk lari, mouse atau panah untuk membidik, klik atau Spasi untuk menembak
